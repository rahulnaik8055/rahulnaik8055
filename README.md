### 📌 Featured Project

**[CanvasFlow](https://github.com/rahulnaik8055/CanvazzFlow)** — Real-time collaborative design canvas (Figma-style)  
`Next.js` `NestJS` `PostgreSQL` `Liveblocks` `Socket.IO`

- Multi-user live editing with cursors, presence, and CRDT-based conflict resolution via Liveblocks
- Dual real-time architecture separating canvas sync (CRDT) from app events (Socket.IO) to protect editing latency
- 10-model relational schema in PostgreSQL/Prisma with hierarchical layers, RBAC, and event-sourced access requests
- Two-layer NestJS guard pipeline (JWT + role-based auth) enforcing owner/editor/viewer permissions across 11 modules
- Canvas rendering engine built on Konva/HTML5 Canvas for smooth performance with hundreds of interactive nodes
- Webhook-driven async persistence: Liveblocks holds live state, changes durably persisted to PostgreSQL off the critical path
